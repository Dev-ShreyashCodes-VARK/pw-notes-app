# PW Notes AI Agent (Android)

An autonomous Android assistant with multi-agent orchestration for extracting study notes from Physics Wallah lecture slides and study PDFs.

## Pre-configured Features
- **App Whitelist Privacy Filter:** Enforces that only permitted apps (like Physics Wallah) can be seen or captured by the AI.
- **Floating Pill:** Draggable floating overlay to capture slides with 1 tap.
- **Strict Transcription Sub-Agent:** Verbatim prompt execution ensuring absolute source fidelity.
- **Human-in-the-Loop Review:** Full editing and approval workflow before page generation.
- **Vertical A4 Visual Notes:** Formatted study pages exported directly to PDF.
